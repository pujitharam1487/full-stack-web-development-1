## How to Upload

1. Extract this ZIP file.
2. Open the extracted `full-stack-web-development` folder.
3. Add your actual PDFs, screenshots, and project files.
4. Create a GitHub repository named `full-stack-web-development`.
5. Upload the contents of this folder to the repository.

## Notes

- `.gitkeep` files are included so GitHub keeps otherwise-empty folders.
- Replace the sample project files with your actual assignment/group-project files when ready.
